## Управление только с клавиатуры

Выполните без мыши во всех трёх курсах.

- [ ] Skip link получает фокус первым и переносит к основному содержанию.
- [ ] Ссылка «Все курсы» и все module dots доступны в логичном порядке.
- [ ] У каждого интерактивного элемента виден focus indicator.
- [ ] Quiz options выбираются клавишами `Tab` + `Enter`/`Space`; кнопки проверки и повтора работают.
- [ ] Итог quiz («Зачёт» / «Нужна повторная попытка») объявляется и остаётся визуально доступным.
- [ ] Glossary tooltip открывается `Enter`/`Space`, закрывается без ловушки фокуса.
- [ ] Architecture cards и layer tabs управляются клавиатурой; arrow keys не перехватываются глобальной навигацией.
- [ ] Chat и flow controls запускаются и повторяются с клавиатуры.
- [ ] Ни один modal/tooltip/интерактив не создаёт keyboard trap.
- [ ] Footer navigation достигается и ведёт по ожидаемым адресам.

## Экранный диктор

Рекомендуемая пара для macOS: Safari + VoiceOver. Зафиксируйте фактическую пару выше.

- [ ] Заголовок страницы, язык `ru` и основной landmark объявляются корректно.
- [ ] Иерархия headings позволяет понять структуру курса без визуального просмотра.
- [ ] Module dots объявляются как обычные кнопки с русскими labels; текущая получает `aria-current`.
- [ ] Progress bar имеет имя либо его назначение однозначно из контекста и обновление не создаёт речевой шум.
- [ ] Quiz option сообщает выбранное состояние; feedback и итоговый score объявляются один раз.
- [ ] Tooltip term имеет понятное имя и определение доступно без мыши.
- [ ] Architecture/layer controls сообщают выбранное или раскрытое состояние и связанное описание.
- [ ] Анимационные chat/flow updates не создают неконтролируемый поток announcements.
- [ ] Emoji или декоративные значки не скрывают смысл текстового label.
- [ ] Все ссылки имеют различимые названия вне окружающего контекста.

## Контраст и принудительные цвета

- [ ] Normal text и labels соответствуют минимум 4.5:1.
- [ ] Large text соответствует минимум 3:1.
- [ ] Focus indicator и границы controls различимы минимум 3:1 относительно соседних цветов.
- [ ] Success/error/warning не различаются только цветом: присутствует текстовый verdict.
- [ ] В Windows High Contrast / forced colors controls, focus и выбранные состояния остаются видимыми либо найденные ограничения записаны и исправлены.
