# NautilusTrader: от котировки до безопасного запуска — 20 часов

Три взаимосвязанных интерактивных курса на русском языке, собранных по актуальной ветке `develop` NautilusTrader.

## Что входит

| Курс | Время | Результат |
|---|---:|---|
| 01. Как устроен торговый движок | 5 ч 30 мин | Ученик трассирует путь данных, различает роли компонентов и понимает событийный жизненный цикл стратегии. |
| 02. Надёжный бэктест | 7 ч | Ученик собирает воспроизводимый исследовательский запуск и ограничивает выводы силой доказательств. |
| 03. Стратегия на Rust: от бэктеста к Live | 7 ч 30 мин | Ученик проектирует нативный контур на Rust от стратегии до последовательных проверок Live, не подменяя готовность одним успешным соединением. |
| **Итого** | **20 ч** | **12 модулей, практические артефакты, проверки понимания и итоговый проект.** |

Публикуйте корень проекта: корневой `index.html` переводит в `courses/index.html`, откуда доступны все курсы и материалы. Для локального просмотра откройте `index.html`. Каждый курс работает без внешних шрифтов, трекеров и обязательной сети.

## Источник и границы

- Репозиторий: `nautechsystems/nautilus_trader`.
- Снимок для подготовки содержания: ветка `develop`, commit `84a98f7f3cc786085496976320c3cb320024217f` от 22 сентября 2026 года.
- Кодовые фрагменты в уроках являются точными непрерывными выдержками из зафиксированного commit и снабжены путями и строками в briefs. Проверка выполняется `verify_source_snippets.py`.
- Учебная программа не является инвестиционной рекомендацией и не доказывает прибыльность стратегии.
- Бэктест, публичный data probe, shadow, canary и live — разные уровни доказательств. Они не взаимозаменяемы.

## Файлы программы

- `CURRICULUM.md` — полный тайминг и результаты обучения.
- `INSTRUCTOR_GUIDE.md` — сценарий проведения, контрольные точки и правила обратной связи.
- `LEARNER_WORKBOOK.md` — рабочая тетрадь и шаблоны артефактов.
- `CAPSTONE.md` — итоговый проект с рубрикой оценки.
- `LABS.md` — практикум из 12 лабораторных работ с входными данными и критериями.
- `INSTRUCTOR_ANSWER_KEY.md` — ожидаемые наблюдения и mastery policy.
- `PILOT_TIMING_RECORD.md` — незаполненный протокол для доказательства реального seat time минимум на трёх участниках.
- `BROWSER_ACCESSIBILITY_QA.md` — протокол desktop/mobile/200%, keyboard-only, screen-reader и reduced-motion проверки release candidate.
- `DOCUMENTS_SITE_QA.md` — фактический browser-smoke отчёт по HTML-документам и их интеграции с сайтом.
- `RELEASE_CANDIDATE_STATUS.md` — актуальный консолидированный статус, закрытые findings и оставшиеся внешние release gates.
- `THIRD_PARTY_NOTICES.md` и `LICENSES/` — атрибуция и полный текст лицензии NautilusTrader.
- `courses/*/briefs/` — подробные сценарии модулей.
- `courses/*/modules/` — интерактивные HTML-модули.
- `courses/docs/` — адаптивные HTML-версии всех документов с оглавлением и print styles.

## Сборка

Для каждого курса запустите его `build.sh` из каталога курса. Скрипт объединит `_base.html`, все файлы из `modules/` и `_footer.html` в `index.html`.

После изменения Markdown-документов обновите HTML-версии (для пересборки нужен Pandoc):

```bash
python3 build_docs.py
```

Статический сайт использует уже собранные страницы и не требует Pandoc или JavaScript для чтения документов.

После сборки выполните:

```bash
python3 verify_courses.py
python3 verify_source_snippets.py --source /path/to/nautilus_trader
```

Второй путь должен указывать на checkout commit `84a98f7f3cc786085496976320c3cb320024217f`.
