Дата: 2026-09-23
Проверяемая сборка: текущий release candidate после python3 build_docs.py
Браузер: Codex in-app browser
Verdict: PASS для document integration и responsive smoke test

Этот verdict относится только к новым HTML-версиям документов и их переходам из сайта. Он не заменяет полный screen-reader/200%-zoom протокол из BROWSER_ACCESSIBILITY_QA.md.

Что проверено

Каталог документов

  • courses/docs/index.html открывается как самостоятельная страница сайта.
  • Присутствуют 14 карточек в четырёх группах: учебные материалы, преподавателю, источники/лицензии и подготовка публикации.
  • На desktop 1440×900 каталог использует три колонки и не создаёт горизонтальный scroll страницы.
  • На mobile 390×844 каталог использует одну колонку; scrollWidth = innerWidth = 390, page overflow отсутствует.

Все 14 документов

Каждая карточка была открыта в браузере на viewport 390×844. Для каждой страницы подтверждено:

  • есть отдельный русский h1;
  • есть три навигационные ссылки: «Все документы», «Материалы», «Курсы»;
  • отсутствует горизонтальный scroll всей страницы;
  • scrollWidth = innerWidth = 390;
  • исходный Markdown представлен как HTML, а не как raw text.

Проверенные страницы:

  1. Программа и расписание.
  2. Практикум: 12 лабораторных работ.
  3. Рабочая тетрадь.
  4. Итоговый проект.
  5. Руководство преподавателя.
  6. Ответы и правила оценивания.
  7. Источники и решения по версии.
  8. Сведения о сторонних материалах.
  9. Лицензирование курса.
  10. Полный текст GNU LGPL 3.0.
  11. Статус release candidate.
  12. Протокол пилотного хронометража.
  13. Проверка в браузерах и доступность.
  14. Исторический publish review.

Длинный документ и таблицы

Для courses/docs/labs.html дополнительно проверено:

  • desktop 1440×900: левое sticky-оглавление отображается, mobile-оглавление скрыто, page overflow отсутствует;
  • mobile: sidebar скрыт, вместо него доступно раскрываемое «Содержание»;
  • браузерное accessibility tree содержит заголовки, списки, таблицы и ссылки на связанные HTML-документы;
  • ссылки INSTRUCTOR_ANSWER_KEY.md и LEARNER_WORKBOOK.md визуально сохраняют понятное имя, но ведут на соответствующие HTML-страницы.

Встраивание в существующий сайт

  • courses/resources.html ведёт к HTML-версиям curriculum, guide, pilot QA, labs, workbook, answer key, capstone, source notes и лицензий.
  • courses/index.html содержит переход «Все документы в HTML».
  • Footer каждого курса содержит переход «Документы HTML».
  • В опубликованных HTML-файлах не осталось ссылок href на .md или .txt.
  • Документы используют только локальный docs.css; внешние шрифты и runtime-библиотеки не нужны.

Работа в браузере

  • В консоли проверенных document pages нет error или warning от кода сайта.
  • verify_courses.py проверяет существование документов, совпадение SHA256 с исходниками, целостность ссылок, отсутствие duplicate IDs и release junk.
  • verify_source_snippets.py продолжает проходить независимо от document rendering.

Что намеренно не заявлено

  • Screen reader не проходился человеком от начала до конца.
  • Zoom 200% не проверялся для всех страниц.
  • Forced colors и Windows High Contrast не проверялись.
  • Пилотный хронометраж не проводился.

Эти пункты остаются внешними release gates и не должны считаться закрытыми данным smoke test.
