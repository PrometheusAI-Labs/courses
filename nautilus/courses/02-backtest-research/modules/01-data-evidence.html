Криминалистический архив, а не мешок файлов

Представьте архив улик: важны не только образцы, но и подписи, время и порядок. В исследовании таким архивом становится catalog, а бэктест использует его как вход.

③

Преобразования

④

Граница вывода

Что именно делает код архива

Слева — точный фрагмент проекта. Справа — смысл действий без предположений о качестве источника.

CODE 
# Create a catalog instance
catalog = ParquetDataCatalog(str(CATALOG_PATH))

# Write instrument to the catalog
catalog.write_instruments([instrument])

# Write ticks to the catalog
catalog.write_quote_ticks(ticks)
ПО-РУССКИ

Открыть Parquet-каталог по заранее выбранному пути.

Сохранить описание инструмента, чтобы тики имели однозначный контекст.

Сохранить подготовленные quote ticks как вход исследования.

⚠
Не переносите механику примера бездумно

Удаление каталога даёт чистый учебный запуск, но в реальном исследовании политика хранения и резервного копирования должна быть отдельным решением.
