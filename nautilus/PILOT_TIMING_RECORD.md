# Протокол пилотного хронометража

Этот документ — шаблон release evidence. Он не содержит вымышленных результатов. До публичного релиза заполните его по минимум трём представителям целевой аудитории; плановые 1200 минут из `course-manifest.json` не считаются подтверждённым seat time, пока таблицы ниже пусты.

## Критерии участника

- понимает базовые торговые термины, но ранее не работал с архитектурой NautilusTrader;
- может читать короткие фрагменты Python или Rust с пояснениями, но не обязан писать систему с нуля;
- проходит материал без доступа к instructor answer key;
- не участвовал в создании курса.
