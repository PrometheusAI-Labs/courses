# Учебная программа на 20 часов

## Сквозная логика

Программа идёт от наблюдаемого поведения к внутренней архитектуре, затем к воспроизводимому исследованию и только после этого — к нативному Rust и безопасному live-контуру. Каждый модуль заканчивается артефактом, который можно проверить отдельно от устного объяснения.

## Курс 1 — Как устроен торговый движок (330 минут)

| Модуль | Время | Теория и визуализация | Практика | Проверка |
|---|---:|---|---|---|
| 1. Путь одной котировки | 75 мин | Событийный конвейер: Adapter → DataEngine → Cache → MessageBus → Strategy | Трассировка «пропавшего» QuoteTick | Карта потока + quiz |
| 2. Команда движка | 80 мин | Границы Data, Risk, Execution, Portfolio, Cache, Trader, MessageBus | Раскладка 12 задач по владельцам | Матрица ответственности + quiz |
| 3. Стратегия реагирует | 85 мин | Подписки, callback, warm-up, состояние | Диагностика трёх сломанных жизненных циклов | Debug canvas + quiz |
| 4. Три среды | 90 мин | Backtest, Sandbox, Live и сила доказательств | Построение promotion ladder | GO/NO-GO memo + quiz |

Результат курса: ученик может объяснить путь рыночного события, выбрать владельца логики и отделить повторное использование кода от доказательства live-готовности.

## Курс 2 — Надёжный бэктест (420 минут)

| Модуль | Время | Теория и визуализация | Практика | Проверка |
|---|---:|---|---|---|
| 1. Данные как доказательство | 100 мин | Нормализация, время, сортировка, каталог | Паспорт набора данных и проверки качества | Data evidence sheet + quiz |
| 2. Воспроизводимый запуск | 105 мин | Явные venue/data/engine configs | Сборка run manifest без hidden state | Run manifest + peer review |
| 3. Стратегия как гипотеза | 105 мин | Signal, state, action, assumptions | Разбор EMA cross и проектирование альтернативной гипотезы | Hypothesis card + quiz |
| 4. Границы результата | 110 мин | Детерминизм, модель исполнения, forward/shadow/canary | Классификация утверждений по силе evidence | Evidence report + gate decision |

Результат курса: ученик строит воспроизводимый исследовательский запуск и формулирует только те выводы, которые действительно поддержаны данными и моделью.

## Курс 3 — Стратегия на Rust: от бэктеста к Live (450 минут)

| Модуль | Время | Теория и визуализация | Практика | Проверка |
|---|---:|---|---|---|
| 1. Анатомия Rust-стратегии | 105 мин | StrategyCore, поля домена, конфигурация, wiring | Карта владения состоянием | Rust component map + quiz |
| 2. От события к заявке | 110 мин | Subscription → callback → order → risk → execution | Диагностика четырёх границ | Order trace + quiz |
| 3. Нативный бэктест | 110 мин | Сборка engine/venue/data/strategy | План replay с проверяемыми артефактами | Native validation plan + quiz |
| 4. Live без самообмана | 125 мин | Adapter, auth, reconciliation, shadow, canary, kill switch | Итоговый gate review | Capstone dossier + defence |

Результат курса: ученик может описать и защитить Rust-native архитектуру и план поэтапной валидации, не делая live-выводов из локального build или публичного data probe.

## Правила хронометража

Каждый модуль включает четыре обязательных блока:

1. Интерактивное объяснение и трассировку реального кода.
2. Лабораторная работа с пошаговой проверкой.
3. Самостоятельное задание с сохраняемым артефактом.
4. Прикладной quiz или gate review.

Время рассчитано для обучения с выполнением практики, а не для быстрого просмотра HTML. Преподаватель может разделить программу на пять дней по четыре часа или десять занятий по два часа.
