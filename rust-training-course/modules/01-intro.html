What Is This Thing?

A quick tour of Microsoft's open-source Rust training — seven books, seven on-ramps, one language.

The Big Picture

Imagine you want to learn Rust — a programming language that companies like Microsoft, Google, and Amazon use for their most demanding software. Where do you start?

If you search online, you will find hundreds of tutorials. Most of them assume you are starting from zero. But what if you already know Python, or C#, or C++? You do not need someone to explain what a variable is — you need someone to explain how Rust thinks differently from the language you already know.

That is exactly what Microsoft built. The RustTraining project is a collection of seven free training books, each designed for people coming from different programming backgrounds. Think of it like a music school with different departments: every department teaches the same instrument, but a guitarist learns differently from a pianist, even though they are both learning drums.

Three of the books are called Bridge books — they connect what you already know to Rust:

C
Rust for C/C++ Programmers

Ownership as an upgrade from manual memory management. If you think in pointers and malloc, this book speaks your language.

C#
Rust for C# Programmers

From garbage collection to ownership. Maps familiar .NET patterns — LINQ, async/await, generics — to their Rust equivalents.

Py
Rust for Python Programmers

From dynamic typing to static guarantees. Shows how Rust replaces duck typing with traits, and why that is a feature, not a limitation.

The Learning Paths

Beyond the three Bridge books, the project offers four more books that go deeper into specific areas of Rust. Here is the full lineup:

C
Rust for C/C++ Programmers

Bridge — 16 chapters mapping systems-level concepts to Rust's ownership model.

C#
Rust for C# Programmers

Bridge — 15 chapters connecting .NET patterns to Rust idioms.

Py
Rust for Python Programmers

Bridge — 15 chapters translating dynamic Python thinking into static Rust thinking.

~
Async Rust

Deep Dive — futures, Tokio, streams, and cancellation safety in 15 chapters.

P
Rust Patterns

Advanced — design patterns, idiomatic APIs, and architectural best practices.

T
Type-Driven Correctness

Expert — encoding business rules in the type system so invalid states are unrepresentable.

E
Rust Engineering Practices

Practices — CI/CD, testing strategies, project structure, and team workflows.

💡
Key Insight

This project inverts traditional education. Instead of "learn everything, then build," it meets you where you are. Each Bridge book assumes you are already a competent programmer — it just shows you how Rust does things differently from the language you already think in.

What Makes These Books Special

These are not ordinary PDFs or blog posts. Every book is built with mdbook, a tool that turns plain Markdown files into interactive websites. Here are the four features that make them stand out:

1
Mermaid diagrams that visualize complex concepts

Ownership graphs, async state machines, type hierarchies — all rendered as clean diagrams right inside the chapter, generated from simple text descriptions.

2
Editable Rust playgrounds (run code in the browser)

Every code example is editable. Change a line, click Run, and see the output instantly — no local Rust installation needed.

3
Exercises at the end of each chapter

Each chapter ends with hands-on exercises that reinforce the concepts you just learned, giving you a chance to practice before moving on.

4
Full-text search across all chapters

Need to find where traits are discussed? The built-in search indexes every chapter, so you can jump directly to the concept you need.

Here is how the playground feature is configured. This snippet comes from the book.toml file — the configuration file that controls how each book is built:

book.toml [output.html.playground] editable = true line-numbers = true
Plain English
[output.html.playground] — This section controls the code examples on the website
editable = true — Let readers change the code and run it — like a mini coding sandbox
line-numbers = true — Show line numbers next to code so readers can follow along easily
