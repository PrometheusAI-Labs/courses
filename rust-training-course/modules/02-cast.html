The Workspace Glue

The root Cargo.toml ties the whole project together. Let's read it line by line.

CODE 
[workspace]
resolver = "2"
members = ["xtask"]
PLAIN ENGLISH

This file defines a workspace — a way to group related Rust projects together under one roof

Use the modern dependency resolution strategy (version 2 is smarter about avoiding conflicts). The resolver handles all of that automatically.

The only actual Rust program in this workspace is xtask — the build tool that manages everything

💡
Key Insight

The 7 books aren't Rust programs — they're Markdown text files. The only actual code is the xtask build tool that transforms them into websites.
